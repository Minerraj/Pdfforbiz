    Why didn't my file get much smaller?

    This tool cleans up document structure — duplicate fonts, unused objects, formatting bloat. Scanned or image-heavy PDFs are dominated by image data, which this method doesn't recompress, so gains will be smaller on those files.

    Will compressing reduce quality?

    No — this method doesn't touch page content or image resolution, so what you see stays exactly the same.
