How to Merge Bank Statement PDFs Into One File

Loan applications, mortgage underwriting, and audits often ask for "the last 3-6 months of bank statements" — which usually means downloading several separate PDFs from your bank and needing to hand them over as one file, not a scattered email chain of attachments.

Why lenders and auditors want one file

Reviewing six separate PDF attachments is slower and easier to lose track of than one continuous document. Many application portals also only allow a single file upload per field, forcing the issue directly.

The process

  1. Download each monthly statement from your bank's portal as a PDF.
  2. Open a PDF merge tool and add all the statements.
  3. Order them chronologically using the reorder arrows — most lenders expect oldest to newest.
  4. Merge and download the combined file.

A few things to check before sending

  • Account numbers are visible on every statement. If you're sending this to someone other than a lender you've already vetted, consider whether you want to redact the account number on anything beyond the last few digits.
  • File size. Six months of statements can add up. If the merged file is too large for an email attachment, compress it before sending.
  • Order matters. Double-check the page order after merging — most reviewers expect chronological order and will flag anything that looks out of sequence.
