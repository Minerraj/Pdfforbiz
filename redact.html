Is this real redaction, or just a black box on top?

Each page is rasterized (turned into a flattened image) on export, so the original text underneath your black boxes no longer exists in the output file — it can't be selected, searched, or copied out.

Will the exported file still look like a normal PDF?

Yes — it opens and displays like any PDF. The only difference is that every page is now an image rather than searchable text, which is what makes the redaction permanent.
