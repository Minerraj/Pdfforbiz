    Where your files go: nowhere. This tool runs entirely in your browser using client-side PDF processing — no upload, no storage, no account.

    How it works

    1. Upload the PDF you want numbered.
    2. Set a starting number and choose bottom-left, center, or right placement.
    3. Click Apply — every page is numbered in one pass, then the file downloads.

    Who uses this

    • Numbering a multi-page contract before it's sent for signature
    • Adding page numbers to a proposal or report for easy reference on a call
    • Continuing numbering into an appendix that starts above page 1

    Can I start numbering from something other than 1?

    Yes — useful if this file is an appendix continuing from a document you've already numbered elsewhere.

    What format are the numbers in?

    Plain numerals (1, 2, 3…) placed in the position you choose at the bottom of each page.
