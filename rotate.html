    How it works

    1. Upload a PDF that's sideways or upside down.
    2. Choose a rotation direction — left, right, or a full 180°.
    3. Download the corrected file — every page is rotated at once.

    Who uses this

    Can I rotate just one page instead of all of them?

    This version rotates the entire file at once. For page-by-page control, use the Redact tool's page viewer as a workaround, or split the file first with the Split tool.

    Will rotating affect quality?

    No — rotation only changes page orientation metadata and doesn't touch the underlying content.

    How do I fix a sideways scanned PDF for free?

    Upload the file, pick a rotation direction (left, right, or 180°), and download — no watermark, no account, no Acrobat required.
